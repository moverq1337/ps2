

#### Задача 1: Произведение трёх чисел 🧮✨
Напишите программу, которая **считывает три целых числа** и выводит их **произведение**! 😎  
Программа должна работать так, чтобы пользователь ввёл три числа, а она выдала их результат перемножения.

**Пример ввода 1:**  
5  
4  
2  

**Пример вывода 1:**  
40  

**Пример ввода 2:**  
0  
3  
78  

**Пример вывода 2:**  
0  

💡 **Подсказка:** Используйте умножение (`*`) и не забудьте про ввод чисел! 🚀

#### Задача 2: Сумма цифр трёхзначного числа 🔢🎉
Напишите программу, которая берёт **трёхзначное число** и находит **сумму его цифр**. 😊  
Например, для числа 179 сумма цифр — это 1 + 7 + 9 = 17.

**Пример ввода 1:**  
179  

**Пример вывода 1:**  
17  

**Пример ввода 2:**  
300  

**Пример вывода 2:**  
3  

💡 **Подсказка:** Подумайте, как разделить число на цифры (деление и остаток могут помочь 😉).  

✨ **Удачи, юные программисты!** Кодьте с улыбкой! 😄
